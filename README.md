# Onigiri Shift（こめ八バイト日誌 大盛り）

駅前のおむすび屋「こめ八」で月曜から金曜まで働き、週末に休むブラウザゲーム。
開業資金を貯めて、いつか自分の店を持つ。

> シンプルな通常版は最初のコミット（`30b6542`）にある。

## 遊び方

1. お客さんの伝票を見る
2. ごはんをよそって、具をえらぶ
3. 2回にぎって（ふんわり）、または3回にぎって（しっかり）、のりを巻く
4. お客さんをタップして渡す

## 通常版から増えたもの

- 週のリズム：月〜金に働き、週末に道具やごほうびを買う
- 目標：開業資金 80,000円で自分の店を開く（達成後も続けられる）
- 仕込み：ごはんは釜の分だけ。減ったら炊く（待ち時間あり）
- 揚げもの：唐揚げ・エビフライは揚げて待つ
- ツナマヨ：ボウルにツナとマヨを入れて混ぜると4個ぶんできる
- にぎり加減：ふんわり／しっかりの好みに合わせるとチップが増える
- お客さん：急ぎの会社員、「いつもの」の常連、途中で注文を変える人
- 昼ピーク：12時台だけ来店が増える

## 動かし方

`index.html` をブラウザで開くだけ。ビルド不要。
スマホの縦持ちでタップ操作に対応。

進行状況はブラウザの localStorage に保存される。

## 構成

```
index.html        画面の骨組みと、下記ファイルの読み込み
css/style.css     色・フォント・レイアウト・アニメーション
js/util.js        小道具（要素の取得、金額の表示、ランダム選択）
js/data.js        データ表（具、申し送り、週末の品ぞろえ、日ごとの難しさ）
js/state.js       状態 S と、保存・読み込み
js/audio.js       音（Web Audio でその場で鳴らす）
js/art.js         絵（おにぎりとお客さんを SVG で組み立てる）
js/seats.js       客席（来店、伝票の表示、渡す処理）
js/bench.js       まな板と手元（ごはん、仕込み、具、にぎる、のり）
js/screens.js     かぶせ画面（タイトル、申し送り、給与明細、週末、エンディング）
js/main.js        進行（1日の開始、毎フレームの更新、終業、起動）
```

モジュール（import/export）は使わず、上の順番で読み込む普通のスクリプト。
そのため `index.html` をダブルクリックで開いても動く。
値段や難しさを変えたいときは `js/data.js` を見る。
