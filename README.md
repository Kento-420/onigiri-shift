# Onigiri Shift（こめ八バイト日誌）

駅前のおむすび屋「こめ八」で昼のシフトをこなすブラウザゲーム。
伝票を見て、にぎって、待たせずに渡す。

## 遊び方

1. お客さんの伝票を見る
2. ごはんをよそって、具をえらぶ
3. 3回にぎって、のりを巻く
4. お客さんをタップして渡す

- 待たせるとお客さんの機嫌が下がり、ゼロになると帰ってしまう
- 早く渡すとチップ、3人連続で渡すとテキパキ手当がつく
- 日が進むと具・のりなし注文・複数個の注文が増える
- 終業時に店長の評価（優・良・可）と給与明細が出る

## 動かし方

`index.html` をブラウザで開くだけ。ビルド不要、1ファイル完結。
スマホの縦持ちでタップ操作に対応。

進行状況（日数・時給・貯金）はブラウザの localStorage に保存される。
