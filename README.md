# Onigiri Shift（こめ八バイト日誌 大盛り）

駅前のおむすび屋「こめ八」で月曜から金曜まで働き、週末に休むブラウザゲーム。
開業資金を貯めて、いつか自分の店を持つ。

> シンプルな通常版は最初のコミット（`30b6542`）にある。

## 遊び方

1. お客さんの伝票を見る
2. ごはんをよそって、具をえらぶ
3. 2回にぎって（ふんわり）、または3回にぎって（しっかり）、のりを巻く
4. お客さんをタップして渡す

## 通常版から増えたもの

- 週のリズム：月〜金に働き、週末に道具やごほうびを買う
- 目標：開業資金 80,000円で自分の店を開く（達成後も続けられる）
- 仕込み：ごはんは釜の分だけ。減ったら炊く（待ち時間あり）
- 揚げもの：唐揚げ・エビフライは揚げて待つ
- ツナマヨ：ツナ→マヨ→混ぜる、で仕込む
- にぎり加減：ふんわり／しっかりの好みに合わせるとチップが増える
- お客さん：急ぎの会社員、「いつもの」の常連、途中で注文を変える人
- 昼ピーク：12時台だけ来店が増える

## 動かし方

`index.html` をブラウザで開くだけ。ビルド不要、1ファイル完結。
スマホの縦持ちでタップ操作に対応。

進行状況はブラウザの localStorage に保存される（通常版とは別枠）。
